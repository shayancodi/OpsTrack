# OpsTrack

Company IT helpdesk / ticket management system.

Employees create support tickets; agents work them; admins manage users, categories, and overview stats.

## Structure

- `frontend/` — React + Vite + TypeScript + Tailwind
- `backend/` — Node.js + Express + TypeScript
- `backend/prisma/` — Prisma schema and migrations (PostgreSQL)

## Status

Stage 0 — repository skeleton. Backend and frontend apps not initialized yet.
